## 👋 About Me

I'm a Computer Science student at the University of Illinois at Chicago who builds test automation that catches real bugs and runs on every commit. Before software, I worked as a forklift operator and inventory associate at Menards, where I redesigned a fulfillment layout and cut retrieval time by 15–20%. That job taught me to look for the step in a process that fails first, and I now look for the same thing in code.

- 🧪 I build **Playwright + TypeScript** frameworks using the Page Object Model, fixtures and data-driven tests
- ⚙️ I run them in **GitHub Actions** across Chromium, Firefox and WebKit, with reports and traces published automatically
- 🔌 I test **REST APIs** with Playwright and Postman, including negative cases, and verify data with **SQL**
- 🛠️ I build full-stack apps (React, Express, PostgreSQL) so I understand the code I'm testing
- 🌍 I'm bilingual in **English and Arabic**, and I'm currently looking for **SDET / QA Automation** roles (IT Support is my second track)
